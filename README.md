ÁPICE — Finanças pessoais

1. Extraia esta pasta do arquivo ZIP.
2. Abra index.html no navegador para usar o aplicativo.
3. Para editar, abra a pasta em seu editor de código e altere index.html.

IMPORTANTE SOBRE SEUS LANÇAMENTOS
Os lançamentos ficam armazenados no navegador e não dentro deste HTML.
Antes de mudar de pasta, navegador ou computador, no aplicativo atual acesse
Dados / Backup e baixe o backup JSON. Depois abra esta cópia e importe o JSON.
O backup inclui os meses registrados e as previsões de despesas recorrentes.

O aplicativo usa bibliotecas e fontes online. Mantenha conexão com a internet.
